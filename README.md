# adaptive-collaboration v0.2

用于高质量、多步骤和长期任务：内部充分分析、核验证据和检查，默认只呈现当前需要理解、决定或操作的信息。内部分析深度、自主执行权限和可见详细度分别控制，提高自主权不会自动增加输出篇幅。

## 使用

选择‘自适应协作 v0.2’或调用 `$adaptive-collaboration`，也可以说‘启用自适应协作 v0.2’。在同一对话里持续生效，直到明确暂停或关闭；简单插问仍会简短回答。暂停后可说‘恢复协作模式’继续。

方向已确定时直接执行；需要规划时最多展示 5 个一级模块。首次没懂先简单重述、给一个例子并说明影响，仍卡住再展开局部结构。你可以说‘展开③’‘③再浅一点’‘③到专家级’‘只展开执行部分’；没有展开请求时不自动展示完整文献和比较过程。

用‘继续自主推进’允许在既定方向内继续；‘这一步先问我’保留当前步骤的决定权；‘暂停重规划’暂停执行并调整路线。临时控制口令不自动带入新对话。

## 与 Trello 配合

需要可用的 Trello 插件及对应项目访问权限。第一次长期管理时指定项目／根卡，或让助手查找现有任务；目标不唯一时只需选择保存位置。普通低风险状态增改可自动处理；删除、批量归档和高影响重构先给具体方案与影响，并取得确认。同一方案已确认过就不反复询问。

任务用稳定 Task ID 和根卡保存当前地图、决策依据、材料链接、阻塞与下一步；不保存整段聊天。新对话说‘恢复 <Task ID>’或‘继续 <任务名>’，助手会读状态、短报当前位置并继续。任务名不唯一会先定位。

Trello 不可用时，只能保留明确标记的待同步快照并推进独立工作，不能保证实时续接。导出快照可作为恢复来源，但不等于验证了实时连接。

阶段、状态或核心结论仍有冲突时，先停下相关推进与下游写入，核对可访问证据；只索取必要信息，不假设能读取旧聊天。最终收尾会自动执行更严格的 QA；硬问题未解决时不虚报完成。短句可完成的必要确认会提供代码框，普通步骤无需逐个确认。

## 内容

- `SKILL.md`：触发与执行入口。
- `references/`：协作、地图、同步、恢复、质检与示例规则。
- `assets/task-state-template.md`：根卡／待同步快照模板。
- `tests/test-cases.md`：行为验收场景；正常使用无需加载。
- `agents/openai.yaml`：显示名称和默认调用提示。
- `CHANGELOG.md`：本次变更及理由。
- `tests/review.md`：当前自检结果与验证范围。

完整技能目录也可作为项目来源；请保留目录结构，并在项目指令中明确要求按本技能执行。导入文件本身不代表已安装原生 Skill。

## 版本保留

当前安装项由 v0.1 原位更新为 v0.2，调用名不变。v0.1 完整文件保留在此前交付的 `adaptive-collaboration-v0.1.zip`，旧版自审记录也在该包内；没有让两个相同触发范围的版本同时生效。v0.2 继续兼容原任务状态模板，不需要迁移或批量重写现有 Trello 卡片。

本版本没有额外脚本；运行依赖当前模型、可用工具和用户授权。验证范围见自检记录，不把规则说明或历史测试当成当前版本的全量实测。
